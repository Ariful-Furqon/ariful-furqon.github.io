# ariful26.github.io

Personal website for GitHub Pages.

## How to publish

1. Open the `ariful26.github.io` repository on GitHub.
2. Select **Add file** → **Upload files**.
3. Upload these files: `index.html`, `style.css`, and `script.js`.
4. Select **Commit changes** to the `main` branch.
5. Open **Settings** → **Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then select **Save**.
6. Wait 1–5 minutes, then visit: `https://ariful2607.github.io`.
